# 任务 18：性能监测与大型工厂预算

正式设置页增加“开始性能监测”和“停止并导出性能报告”。默认关闭，开始新采样会清空上一轮；每项最多保留最近 3600 个样本，指标名最多 48 项。停止冻结样本，导出不包含玩家存档内容，路径为 `user://performance_reports/`，设置页显示实际文件位置。

记录固定步及十二个阶段、模拟更新、帧间隔、模拟积压、内存、绘制调用数、卡牌和线路的 CPU 绘制提交耗时、实际保存耗时。JSON 供后续分析，Markdown 供阅读，包含环境与平均/P50/P95/最大值。监测不改变 tick 数量、速度、暂停状态或持久化游戏状态。

## 本次优化

- 传送带排序原来每次比较都生成两个完整配置；改为每个固定步建立优先级表，排序后清除。拓扑、优先级变化下一步自然生效；库存、电力、容量、配方仍读取实时状态，不跳过生产步骤。
- 空间索引修正负坐标分区、重复 ID、移动和空单元清理；与权威位置同步，兼容导入、撤销等直接修改字典路径。同步仍为线性检查，不宣称所有命中成本都是常数时间。
- 卡牌按视口空间查询裁剪，复用三种样式，缩小视图降低网格与非选中卡片细节；线路按曲线控制点包围盒裁剪，缩小时按颜色/线宽批绘。端口、命中曲线和选中/连线操作保持完整几何精度。
- 工厂夹具发现并复现线路整数配置经 JSON 转为浮点导致保存摘要不一致；编码与摘要归一化采用 JSON 读回表示，保留既有成功浮点存档的摘要兼容性，schema 仍为 v9。

## 验证方法

[夹具规则与复现命令](../../tests/fixtures/README.md)说明三档规模、图形模式和本机趋势比较。正式门禁包含十四场景，性能场景检查采样边界、开关、导出、负坐标/移动/删除、多个缩放下的裁剪等价、动态配置与模拟等价、真实保存和读回。

完整模拟比较使用 30 个固定步；不代替长期压力测试、完整通关或所有 GPU 认证。图形基准测固定视图 SubViewport，帧等待包含渲染和调度；draw_submit 为 CPU 指令提交，不是 GPU 时间。engine_to_test_scene_ready_ms 是引擎启动至测试场景 ready 的时间，不含系统启动进程之前的开销；fixture_create_ms 是生成工厂的成本，不是冷启动。
