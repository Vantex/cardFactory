# 任务 24 验收（2026-09-21）

持久蓝图库、施工队列与导航标记已接入正式桌面入口，按当前受限蓝图和原生物流站模型交付。

## 已交付

- 蓝图库名称、旋转、镜像、兼容配方替换与载具目标进入权威状态；支持新增、更新、删除和受限文本导入导出。仍可导入旧蓝图 v1，导入不会自动部署。
- 立即部署同时检查施工件和载具，失败不修改库存或建筑；排队部署保存独立定义快照，删除或修改原蓝图不改变订单。
- 最多 100 个施工订单，按模拟时间每秒尝试补足，暂停时仍可手动资助。施工件与载具可分别部分预留；施工完成后允许继续等待载具。取消只退未消耗预留，已建建筑保留；退款超过容量时拒绝且不修改状态。
- 默认拒绝重叠；显式开启后复用同位置、同类型、同捕获配置建筑及一致线路，扣除复用成本。载具目标计算已有和在途载具，避免重复购买。灰模不参与生产，预检不发真实创建事件。
- 区域名称、矩形、颜色、所属行星，以及书签位置、缩放进入存档。桌面面板提供创建、更新、重命名、删除和导航，小地图显示标记。区域最多 48、书签最多 24，超过时保留最新项。
- 新状态通过 schema v9 可选字段保存；空扩展不写入，保留旧摘要与旧档兼容。引用、数量、变换、预留和导航数值加载校验接入统一 validator。
