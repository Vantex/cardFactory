## 两种门禁

登记门检查源文件校验、完整 ID 集合、逐项规则规格、合法候选映射、缺口原因、任务归属、人工编号和固定排除名单。缺一项即失败。

最终发布模式 `-RequireComplete` 要求全部非在线项为已验证，并有实际行为检查传入的通过 key；当前必须失败。规则规格中的 pending_behavior 不表示已经执行了该玩法测试。任务 20～26 完成对应规则，任务 27 完成行为金标与人工旅程。
