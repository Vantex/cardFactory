# 任务 21：多电网、优先级与储能验收

日期：2026-09-10。参考 DSPONLINE 1.0.46，冻结提交 472bf62c76b695852b5577e563c1d113192ac731。

## 已交付

- 每个行星独立维护 A/B/C 三个稳定电网；冻结源覆盖规则是同星同网存在电源，不使用距离半径。换网不搬运库存、不重置生产。
- 用电默认优先级 2，按 3→2→1 分配，同级按需求比例分电。可再生和戴森接收功率优先；燃料、枢纽和蓄电器按发电优先级补足缺口。燃料待机不消耗，燃料不会为了充电额外燃烧。
- 蓄电器容量 90 MJ、充放电 900 kW；能量枢纽每个电池 90 MJ、45 MW、输入输出容量 120。可再生余量先供应枢纽，再充蓄电器；满输出暂停转换。
- 检查器可批量修改电网、用电/发电优先级和枢纽模式，显示覆盖、供需、储能及缺料/满输出提示。命令先预检全部对象，再提交。
- 新建枢纽默认充电配方，建造栏和手工制造提供正式入口。已有电脑分辨率、字号、滚动和键盘焦点适配保留。
- schema v9 添加可选建筑字段，缺省仍为 A 网和原默认优先级；运行派生字段不存盘。磁盘写入/读回保留储能和优先级，统一 JSON 数值摘要类型。

## 对齐边界与承接

本轮交付电网调度和储能核心，并非所有源电力条目已对齐。矩阵仍保留“实现中/未实现”，没有新增源行为金标“已验证”。任务 22 必须接续完整发电设备与燃料目录（包括地热、聚变、人造恒星）、源施工/配方成本、设备动态需求与待机功耗，并补充多燃料选择入口；任务 27 负责跨实现行为金标。

当前原生生产设备仍使用额定需求，尚未按源实现的缺料/堵塞/闲置状态降低负载。新增储能施工件和空电池采用原生临时手工材料成本，不能当作源配方数值对齐。为避免资源丢失，带储能设备禁止直接拆除，枢纽含部分转换电池时禁止切换模式；这两项保护策略也需在最终源行为对照中明确核对。

电脑人工复核：制造并放置储能设备，在检查器换 A/B 网并观察断电；同网加入低/高优先级负载；向充电枢纽投空电池，收取满电池，再放入放电枢纽；保存/重载后检查剩余能量。尚未记录完整人工旅程通过。
