# 任务 13 验收：行星与星际物流站

## 手动旅程

1. 在已建立基础研究产线的本地游戏中手工制作行星物流站两座、运输机一架。空闲检查器点击建造，放置在有电的母星。
2. 选择源站打开配置，槽 1 选铁矿、供应、容量 100、最低装载 10%；目标站槽 1 选铁矿、需求。向源站转入 40 铁矿和一架运输机，观察两批送达与返航。源站、目标站、在途及托盘总铁矿数保持不变。
3. 从矿机连接源站、从目标站连接熔炉；确认铁矿通过物流进入冶炼生产。选择多种槽位物品时可在 Inspector 切换线路输出。
4. 点击停止派遣，已有载具继续送达、返航；返航后修改槽容量、模式、最低装载与优先级。多选物流站批量应用；选择中任一站锁定或存在航线时应整批拒绝。
5. 解锁星际物流，手工制造两座星际站与飞船；殖民另一行星并在两侧供电。配置相同物品供需，转入真实飞船和货物。累计跨行星送达 20 件后，战役工作台完成「完成跨行星材料运输」。
6. 用手工翘曲器勘探另一个恒星系并建立已殖民目标站。跨星系源站缺少 2 枚翘曲器时不能出发，补足后只扣一次往返成本。观察距离决定航程。
7. 飞船出发后保存、退出、继续；检查相同在途货物与载具归属。停止派遣后等待返航，再拆除，确认返还真实库存、停泊载具和施工件。目标停电应等待卸货，不丢失货物。

## 自动验证边界

统一门禁的 `TestGalaxyLogistics` 包含任务 13 回归：真实固定 tick、暂停、供需和优先级、公平调度、载具与货物转移、失败原子性、断电、目标满、在途预留、往返翘曲器、跨星系科技门、JSON/真实槽位保存加载、v6 迁移、损坏航线拒绝、正式 UI 命令与输入命中，以及 10/50/100 站确定性夹具。

定向场景使用合法预置材料、科技和殖民状态来隔离物流规则；手工制作和基础研究链分别有真实系统回归。因此不宣称已完成人工从新游戏到跨星系工业链的通关。

当前物流施工件和手工翘曲器使用精简目录配方，尚未对齐 DSPONLINE 的完整工业数值。尚未提供物流槽配置的蓝图复制。
