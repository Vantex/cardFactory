# 任务 17 桌面验收记录

本次以用户修订后的范围为准：不做国际化、不做手机适配，保留中文与电脑操作方式。

## 交付行为

- 开始菜单及工厂顶栏的“设置”可修改亮/暗主题、80%～200% 字号、紧凑/舒适密度、滚轮方向与手柄光标速度。设备文件为 `user://device_settings.cfg`，独立于所有 GameState 和存档槽位；提交成功才应用，失败保留当前值。
- 保留桌面顶栏、左右侧栏和建造坞。最小窗口 1000×600，超出区域使用滚动；大字号按实际最小尺寸重新排列。主题应用到动态控件，焦点具有可见边框，错误和状态仍有文字说明。
- 保留鼠标放置、拖动、端口连线、右键/中键平移、滚轮缩放和 Q/W/E/R/T、Space、1/2/3 等快捷键。
- Tab / 方向键导航界面，Enter / A 确认，Escape / B 返回。F6 / Y 切换界面和画布焦点；画布方向键 / 左摇杆移动光标，Enter / A 选择或放置，M / 左摇杆按下移动，C / 右摇杆按下连线，Delete / X 请求删除，减号/等号或 LB/RB 缩放，右摇杆平移。模态确认显示时不能用画布快捷键绕过它。

## 自动验证

第十三场景 `TestProductShell` 纳入 `tools/run_tests.ps1`。覆盖设置重载、非法值及写入失败、设置与 GameState 隔离、正式菜单入口、切换槽位保留偏好、1000×600、1152×648、1920×1080、2560×1440、3840×2160、2560×1080 与 80% / 100% / 200% 字号组合、各工作区返回、实际控件字体、鼠标拖动、键盘光标、手柄放置/移动/连线及删除确认。

测试使用独立临时设备文件和槽位目录；门禁以 `--device-settings` 给每个进程指定唯一文件，避免玩家设备设置影响测试或被测试覆盖。物流站界面使用含真实四槽结构的测试数据。

## 渲染及人工边界

通过 Godot OpenGL Compatibility 渲染正式 Main 的子视口，核对 200% 字号的设置页及桌面窗口、1080p、1440p、4K 与宽屏尺寸，捕获路径为可重新生成的 `.godot/task17-settings.png`、`.godot/task17-factory-1000x600.png`、`.godot/task17-factory-1152x648.png`。修复了顶栏文字竖向折行和建造坞高度不足。

这不是实体手柄硬件认证或完整人工通关，也没有测试所有操作系统的高 DPI、所有分辨率或屏幕阅读器。无手机布局、触摸手势或英文翻译。引擎仍可能报告沙箱下 user:// 日志、着色器缓存和根证书读取受限；它们与脚本错误分开记录。

分辨率适配使用当前 Viewport 的可用尺寸，窗口缩放时自动重算，兼容 Godot 已有的窗口拉伸与高 DPI 坐标，不叠加读取主屏幕物理像素而重复缩放。以 1152×648 为参考，按宽高可容纳比例计算自动 UI 比例（85%～400%），再叠加用户字号；侧栏宽度有窗口占比上限，为画布保留空间。顶栏、建造坞、小地图、滚动条和画布命中区域同步更新，自动调整不写回字号偏好，也不改变 GameState。设置页显示当前可用尺寸和自动比例。

最终验证：完整十三场景门禁退出 0，成功标记各一次；无脚本/解析错误或生命周期泄漏。Main 无窗口启动 120 帧退出 0，OpenGL 渲染版 TestProductShell 退出 0，六种桌面尺寸与三个字号档位通过。
