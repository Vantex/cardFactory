# 任务 14：戴森云与戴森球

用户已授权继续下一项；范围为路线图任务 14，不包含任务 15 的正式胜利状态。

## 实现顺序与约束

1. 新增 `TestDysonEndgame` 权威入口，覆盖发射耗材、帆寿命、轨道/恒星系隔离、火箭结构点、壳面吸附、射线接收、保存恢复与失败原子性。
2. schema v8 增加每恒星系戴森状态和整数 tick；轨道、分批到期太阳帆、层、节点结构点与壳面保存在 GameState。v7 迁移为空状态，不赠送材料或功率。
3. `data/dyson.json` 定义设备发射规则、寿命、结构成本、吸附速度和单位功率。到期处理先于电力，发射/吸附在线路之后；欠电按倍率降低发射进度。太阳帆只有云中存活、壳面吸附、到期三种去向；火箭逐件转成结构点。
4. 所有接收站按本星系可用功率与各站接收上限分配，总领取不超过发电；领取后进入接收站所在行星电网，不跨星系分享。未建设戴森工程时接收站输出为零。
5. 正式戴森工作区支持恒星系、轨道/层参数、节点/壳面计划、材料缺口、当前/预计功率、设备目标与耗材装载；建造和生产链从现有精简目录可达。
6. 运行完整十一场景门禁和 Main 启动验证，更新当前文档；仅将本任务路线图勾选提交，保留用户扩展及窗口配置，提交本地 main，不推送。

## 领域选择

每星系最多 8 轨道、8 层，每层最多 16 节点和一个闭合壳面。壳面需至少 3 个不重复节点，其结构完成后以固定速度从关联轨道吸附太阳帆；吸附后不再衰减。已消耗材料的计划不可直接删除，避免无声丢失结构或帆。发射设备只能指向自身行星所属星系的轨道或层。

当前目录已有太阳帆、球组件和运载火箭物品，但高级产线未全部开放；本任务补可由现有材料生产的阶段配方，不声称完整 DSPONLINE 数值对齐。规划操作不直接赠送结构或电力。人工完整通关与独立复审只按实际发生情况报告。
