## 2. 功能测试清单

### 2.1 实体管理测试

| 测试项 | 操作方法 | 预期结果 |
|--------|----------|----------|
| 移动单个实体 | 按Q放置矿机，点击并拖拽 | 矿机跟随鼠标移动 |
| 批量移动 | 放置多个建筑，框选后拖拽 | 所有选中建筑一起移动 |
| 批量删除 | 放置多个建筑，框选后按Delete | 所有选中建筑被删除 |
| 设置配方 | 点击熔炉，选择配方 | 配方显示在建筑上 |
| 交互锁定 | 右键建筑，选择锁定 | 建筑无法移动 |

### 2.2 建筑升级测试

| 测试项 | 操作方法 | 预期结果 |
|--------|----------|----------|
| 升级制造台 | 放置Mk.I，点击升级按钮 | 变为Mk.II，速度提升 |
| 升级熔炉 | 放置arc_smelter，点击升级 | 变为plane_smelter |
| 升级传送带 | 放置Mk.I传送带，点击升级 | 变为Mk.II，速度x2 |
| 升级分拣器 | 放置Mk.I分拣器，点击升级 | 变为Mk.II，速度x2 |

### 2.3 传送带系统测试

| 测试项 | 操作方法 | 预期结果 |
|--------|----------|----------|
| 设置通道数 | 点击传送带，设置通道为2 | 传送带宽度增加 |
| 设置优先级 | 点击传送带，设置优先级为1 | 传送带颜色变化 |
| 设置堆叠 | 点击传送带，设置堆叠为4 | 物品堆叠显示 |
| 设置监控 | 点击传送带，启用监控 | 显示流量数据 |
| 设置路由 | 点击传送带，选择bezier模式 | 连线变为曲线 |

### 2.4 分拣器系统测试

| 测试项 | 操作方法 | 预期结果 |
|--------|----------|----------|
| 设置方向 | 点击分拣器，选择方向 | 分拣器旋转 |
| 设置过滤 | 点击分拣器，选择物品 | 只分拣指定物品 |
| 升级分拣器 | 点击升级按钮 | 速度提升 |

### 2.5 电力系统测试

| 测试项 | 操作方法 | 预期结果 |
|--------|----------|----------|
| 设置电力网格 | 点击建筑，选择grid-a | 建筑颜色变化 |
| 设置电力优先级 | 点击建筑，设置优先级 | 电力分配变化 |
| 设置发电优先级 | 点击发电机，设置优先级 | 发电顺序变化 |

## 4. 压力测试

### 4.1 大量建筑测试

**测试方法：**
1. 放置100个建筑
2. 观察帧率
3. 测试移动、删除操作

**预期结果：**
- 帧率 > 30 FPS
- 操作响应时间 < 0.1秒

### 4.2 大量连线测试

**测试方法：**
1. 放置20个建筑
2. 创建50条连线
3. 观察渲染性能

**预期结果：**
- 帧率 > 30 FPS
- 连线动画流畅
