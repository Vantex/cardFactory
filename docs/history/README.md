## 使用规则

- 历史计划中未勾选的项目不自动成为当前待办。
- 历史计划中已勾选的项目也不能单独证明当前代码仍然具备该能力。
- 历史审计的“待修复”结论可能已经过期，必须重新检查当前代码。
- 历史命令中的文件路径保留原交付语境，执行前先核对当前目录结构。
- 需要恢复决策背景时，连同同批次的规格、计划、测试和架构工件一起阅读。
